# MERCY v5 — Parked research experiment

**Not released, not loaded by the live website.** The [research.js](research.js) module is a standalone experimental utility, retained for future evaluation only.

It includes a limited goal/curiosity supervisor, diagnostic test scaffolding, and an in-browser proposal ledger. It does **not** modify model weights, deploy new code, operate real hardware, or prove consciousness. The **live v2 application does not import or depend on this module**; v2's curiosity is handled by the v2 engine and its existing opt-in speech scheduler.

Future versions will be built and introduced one at a time, after agreeing on scope and verifying their behavior. Experimental code in this folder is not a commitment to a final roadmap or hardware design.
